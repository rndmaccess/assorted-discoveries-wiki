About

The dyed lantern is a variant of the lantern that comes in all 16 dye↗ colors.

Obtaining

Breaking

Dyed lanterns can be broken with any tool, and always drop as an item, but using a pickaxe is the fastest.

Crafting

Craft a dyed lantern in a crafting table by placing a lantern and any color of dye in any arrangement.

Usage

Placement

Dyed lanterns act exactly like a normal lanterns↗ when placed.

Technical

Configuration

Toggles the availability of dyed lanterns:

  • In-Game Screen Name: Enable Dyed Lanterns
  • Config File Key: enable_dyed_lanterns
    • true / Yes: Enabled (Default)
    • false / No: Disabled and hidden
