About

Witch's cradle soup is a swamp food item that can be crafted from witch's cradle branches.

Obtaining

Crafting

Craft witch's cradle soup in a crafting table by placing six witch's cradle branches and a bowl in any arrangement.

Usage

Food

Witch's cradle soup can be consumed by pressing and holding the use control. Drinking one restores 6 hunger (3 drumsticks) and 7.2 saturation, grants Night Vision for 2 minutes, and returns an empty bowl.

Advancement

The "Is this even edible!?" advancement is unlocked by consuming witch's cradle soup.

Technical

Configuration

Witch's cradle soup is enabled/disabled indirectly with the witch's cradle config setting.

  • In-Game Screen Name: Enable Witch's Cradles
  • Config File Key: enable_witchs_cradles

Visit the witch's cradle branch page for more information.
