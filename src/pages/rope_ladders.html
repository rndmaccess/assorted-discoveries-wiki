Decorative Blocks Farming & Food

About

The rope ladder is a decorative block that can be hung from blocks!

Placing

Rope ladders can be placed on any solid block.

Extension

To extend any rope ladder simply place↗ the rope ladder while targeting another rope ladder of the same type.

Rope ladders can only be extended up to 16 blocks away from a support block. Once this limit is reached, there must be another supporting block placed behind the last ladder.

Breaking

Rope ladders can be broken with any item or by hand, but the axe↗ is the fastest! Any rope ladders that are unsupported will break when the supporting block is removed.

Crafting Recipe

3

Craft three rope ladders in a crafting table by placing string in the corners and any planks in the middle row.

Technical

Show Configuration

Toggles the availability of rope ladders.

  • In-Game Screen Name: Enable Rope Ladders
  • Config File Key: enable_rope_ladders
    • true / Yes: Enabled (Default)
    • false / No: Disabled and hidden
