Decorative Blocks Farming & Food

About

The dirt slab, coarse dirt slab, and rooted dirt slab are decorative slab↗ variants of the various blocks.

Obtaining

Breaking

Breaking a single slab drops one slab, while a double slab drops two, similarly to vanilla slabs↗.

Making Path Slabs

Any variant of dirt slab can be made into a dirt path slab by using a shovel↗ on it.

Crafting

6

Craft six dirt, coarse dirt, or rooted dirt slabs in a crafting table by placing three appropriate dirt blocks in a single row.

Usage

Placing Plants

Dirt, coarse dirt, and rooted dirt slabs support any plants that can be planted on dirt ↗.

Only the top and double variants support plants normally. However, if the Slabbed mod↗ is installed the bottom variant will support plants as well.

Double Slabs

Only two dirt slabs of the same type can form a double slab unless a different mod changes this behavior, similarly to normal slabs↗.

Technical

Configuration

Toggles the availability of dirt slabs, coarse dirt slabs, rooted dirt slabs, grass slabs, podzol slabs, mycelium slabs, and dirt path slabs:

  • In-Game Screen Name: Enable Dirt Slabs
  • Config File Key: enable_dirt_slabs
    • true / Yes: Enabled (Default)
    • false / No: Disabled and hidden
