About

Wooden walls are decorative blocks. These blocks come in 12 variants, one for each type of unmodded wood.

A stripped wooden wall is a variant of the wooden wall. Once stripped, it cannot be reversed.

Stripping

Any wooden wall can be stripped by using an axe↗ on it. Stripped wooden walls can also be obtained directly through crafting↗.

Crafting Recipe

6

Craft six walls in a crafting table by filling the middle and bottom rows entirely with the same type of logs, wood, stems, hyphae, or blocks of bamboo.

6

Craft six stripped walls in a crafting table by filling the middle and bottom rows entirely with the same type of stripped logs, wood, stems, hyphae, or blocks of bamboo.

For a list of tags used in these recipes, see the tags section.

Configuration

Unstripped Walls

  • In-Game Screen Name: Enable Wooden Walls
  • Config File Key: enable_wooden_walls
  • Default: true / Yes

Determines whether wooden walls can be obtained.

  • true / Yes: Wooden walls are enabled.
  • false / No: Wooden walls are disabled and hidden.

Stripped Walls

  • In-Game Screen Name: Enable Stripped Wooden Walls
  • Config File Key: enable_stripped_wooden_walls
  • Default: true / Yes

Determines whether stripped wooden walls can be obtained.

Note: If wooden walls are disabled, stripped wooden walls can still be obtained through crafting.

  • true / Yes: Stripped wooden walls are enabled.
  • false / No: Stripped wooden walls are disabled and hidden.
