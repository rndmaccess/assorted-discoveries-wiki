About

Dried blood kelp is a food item that is obtained from drying blood kelp.

The dried blood kelp block is a decorative block that can be used to store dried blood kelp.

Crafting Recipe

Cook a blood kelp item in a furnace or smoker to make dried blood kelp.

Craft a green onion crate by filling the crafting table with nine green onions.

9

Craft nine green onions from a green onion crate by placing it in a crafting table in any arrangement.

Technical

Configuration

Dried blood kelp and dried blood kelp blocks are enabled/disabled indirectly with the blood kelp config setting.

  • In-Game Screen Name: Enable Blood Kelp
  • Config File Key: enable_blood_kelp

Visit the blood kelp page for more information.
