Decorative Blocks Farming & Food

About

Found in outer End island biomes, the short ender grass and snapdragon are decorative blocks that emit ender particles similar to endermen.

Obtaining

Natural generation

Short ender grass and snapdragons can be found in both vanilla and modded outer End island biomes on land. Without other mods installed, this is limited to the end barrens↗, end highlands↗, end midlands↗, and small end islands↗ biomes.

Bone Meal

Using↗ bone meal on end stone↗ generates a patch of short ender grass with snapdragons interspersed throughout.

Dispenser

Bone meal can also be used via a dispenser aimed at an end stone block. This triggers the same plant growth behavior as manual application, generating a patch of short ender grass interspersed with snapdragons.

Breaking

Short ender grass and snapdragons always drop themselves when broken.

Usage

Placing

Short ender grass and snapdragons can be placed on end stone↗.

Crafting

Craft a spruce cone crate by filling the crafting table with nine spruce cones.

9

Craft nine spruce cones from a spruce cone crate by placing it in a crafting table in any arrangement.

Technical

Configuration

Toggles the world generation and availability of short ender grass, snapdragons, and snapdragon crates.

  • In-Game Screen Name: Enable Ender Plants
  • Config File Key: enable_ender_plants
    • true / Yes: Enabled (Default)
    • false / No: Disabled and hidden

History

Prior to version 3.0.0, snapdragons would teleport the player upon contact. This behavior has since been removed.
