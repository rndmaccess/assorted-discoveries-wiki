About

Found in flower forest biomes, the wild green onions block is your initial source for green onion seeds.

Obtaining

Natural generation

Wild green onions can be found in both vanilla and modded flower forest biomes on land. Without other mods installed, this is limited to the flower forest↗ biome.

Breaking

Breaking a wild green onion plant by hand drops 1 to 4 green onion seeds. Using shears↗ drops the plant block itself instead.

Usage

Placing

Wild green onions can be planted on the following blocks:

  • grass blocks↗
  • mycelium↗
  • podzol↗
  • dirt↗
  • coarse dirt↗
  • rooted dirt↗
  • farmland↗
  • mud↗
  • muddy mangrove roots↗
  • moss blocks↗
  • pale moss blocks↗
  • dirt slabs
  • grass slabs
  • overworld planter boxes

Any blocks added to the minecraft:supports_vegetation tag are also supported.

Technical

Configuration

Wild green onions are enabled/disabled indirectly with the green onions config setting.

  • In-Game Screen Name: Enable Green Onions
  • Config File Key: enable_green_onions

Visit the green onion seeds page for more information.
