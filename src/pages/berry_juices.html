About

Blueberry juice is a food item that is made from blueberries.

Sweet berry juice is a food item that is made from sweet berries.

This page covers overworld berry juices. For nether juices, see nether berry juices.

Usage

Food

Both blueberry juice and sweet berry juice can be consumed by pressing and holding the use control. These juices stack up to 16 and take 1.6 seconds (32 ticks) to consume. Drinking either juice restores 6 hunger (3 drumsticks) and 9.6 saturation.

Obtaining

Crafting

Craft blueberry juice in a crafting table by placing blueberries in a plus shape around a central glass bottle.

Craft sweet berry juice in a crafting table by placing sweet berries in a plus shape around a central glass bottle.

Technical

Configuration

Blueberry Juice

Toggles the availability of blueberry juice.

  • In-Game Screen Name: Enable Blueberry Juice
  • Config File Key: enable_blueberry_juice
    • true / Yes: Enabled (Default)
    • false / No: Disabled and hidden

Dependency: If blueberries are disabled, blueberry juice will be automatically disabled as well. Visit the blueberries page to read more about this.

Sweet Berry Juice

Toggles the availability of sweet berry juice.

  • In-Game Screen Name: Enable Sweet Berry Juice
  • Config File Key: enable_sweet_berry_juice
    • true / Yes: Enabled (Default)
    • false / No: Disabled and hidden
